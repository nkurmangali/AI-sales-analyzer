# Разбор звонков с лидами

Загружаете запись созвона с лидом — получаете фидбек:

- резюме звонка;
- потребности и возражения (с таймкодами и оценкой отработки);
- три конкретных замечания менеджеру с таймкодами, цитатой и лучшей формулировкой;
- следующий шаг;
- готовое фоллоу-ап сообщение лиду.

Клик по таймкоду перематывает запись к нужному моменту. Можно вместо записи вставить готовый транскрипт.

## Как это работает

1. Браузер загружает файл напрямую в **Vercel Blob** (`/api/upload` выдаёт токен) — так обходится лимит 4.5 МБ на запрос к функции.
2. `/api/analyze` отдаёт ссылку на файл в **Deepgram**: распознавание речи с разметкой спикеров и таймкодами. После этого файл удаляется из Blob.
3. Транскрипт уходит в **Claude** (`claude-opus-5-5`) со структурированным выводом (схема в `lib/analyze.ts`).

## Деплой на Vercel

1. Vercel → **Add New → Project** → импортируйте этот репозиторий (фреймворк определится как Next.js).
2. В проекте: **Storage → Create → Blob** и подключите хранилище к проекту — `BLOB_READ_WRITE_TOKEN` добавится сам.
3. **Settings → Environment Variables**:
   - `ANTHROPIC_API_KEY` — ключ с https://console.anthropic.com
   - `DEEPGRAM_API_KEY` — ключ с https://console.deepgram.com
   - `APP_PASSWORD` — рекомендуется: пароль на вход (логин любой), чтобы посторонние не тратили ключи
   - необязательно: `DEEPGRAM_MODEL` (по умолчанию `nova-2`), `DEEPGRAM_LANGUAGE` (по умолчанию `ru`)
4. **Redeploy**. Дальше каждый пуш в `main` деплоится автоматически.

Функция анализа рассчитана на 300 секунд (`maxDuration`) — этого хватает на звонки длиной около часа.

## Локальный запуск

```bash
npm install
cp .env.example .env.local   # заполните ключи
npm run dev
```

Для загрузки аудио локально нужен `BLOB_READ_WRITE_TOKEN` (можно взять командой `vercel env pull`). Режим «Готовый транскрипт» работает и без него, и без Deepgram.
